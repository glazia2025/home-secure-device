KEY FUNCTION: button_task() — polling loop every 100 ms on GPIO21

GPIO21 (active-low, internal pull-up) → 50 ms debounce → mode-dependent handler:
  • MODE_IDLE            → Set MODE_HUB_PAIRING, start BLE
  • MODE_FINGERPRINT_ENROLL → Start fingerprint_enroll_task()
  • MODE_OPERATIONAL     → Set MODE_SENSOR_PAIRING, enable server pairing window

FLOW:
  MODE_IDLE
    ↓ [button press]
  MODE_HUB_PAIRING → [BLE: SSID/pwd/token from phone] → MODE_WIFI_CONNECTING
    ↓ [WiFi success, first boot]
  api_register_hub() [POST /api/device/hubs/register]
    ↓ [check fp_is_enrolled()]
  MODE_FINGERPRINT_ENROLL [if not enrolled]
    ↓ [button press]
  fingerprint_enroll_task() → fp_enroll() → nvs_save_fp_enrolled(true)
    ↓ [success]
  MODE_OPERATIONAL ✓

SENSOR: R307 Capacitive Fingerprint Module
UART2: TX=GPIO43, RX=GPIO44, 57600 baud, 8N1 odd parity

PUBLIC API:
  esp_err_t fp_init()          — Initialize UART2
  esp_err_t fp_enroll()        — Double-scan, store in R307 slot 1, set NVS flag
  esp_err_t fp_verify()        — Single-scan, search master template, check match
  bool fp_is_enrolled()        — Check NVS flag

ENROLLMENT PROCESS (button press in MODE_FINGERPRINT_ENROLL):
  1. fingerprint_enroll_task() spawned from button_task()
  2. fp_enroll() → two scans + template generation → R307 onboard storage
  3. nvs_save_fp_enrolled(true) → NVS "glazia" namespace
  4. If success: MODE_OPERATIONAL; if fail: stay in FINGERPRINT_ENROLL (retry)

VERIFICATION PROCESS (touch toggle-OFF in MODE_OPERATIONAL):
  1. critical_toggle_cb() intercepts toggle-OFF attempt
  2. Revert toggle to ON immediately
  3. MODE_FINGERPRINT_VERIFY → fingerprint_verify_task()
  4. fp_verify() → single-scan + compare vs. master
  5. If match: allow toggle OFF + disarm; else: deny + keep toggle ON
